# yomi (読み)

Терминальная читалка манги для Linux. Локальные CBZ и каталоги с
картинками, библиотека с прогрессом чтения, графика прямо в терминале —
без браузера, одним статическим бинарником.

> **Статус: в разработке.** Работают чтение, библиотека и сборка CBZ.
>
> Загрузки из сети в yomi нет — сознательно. Единственный крупный
> источник с открытым API не отдаёт лицензированные тайтлы, а это как раз
> всё популярное; для русскоязычного читателя такая функция создавала бы
> ожидание, которое не выполняется. Наработки сохранены в ветке `net`
> на случай, если появится источник, который можно поддержать честно.

## Установка

Готовых сборок пока нет, собирается из исходников:

```bash
git clone https://github.com/Champloot/yomi.git
cd yomi
cargo build --release
./target/release/yomi --help
```

Нужен Rust 1.75 или новее. На NixOS достаточно `nix develop` —
подробности в [docs/nixos.md](docs/nixos.md).

## Чтение

```bash
yomi read ~/Манга/Тайтл/Том\ 1.cbz    # архив
yomi read ~/Манга/Тайтл/Том\ 1/       # каталог с картинками
yomi read обложка.png                  # одиночная картинка
```

Направление чтения по умолчанию — справа налево, как в манге:
**стрелка влево листает вперёд**. Для комиксов — `--direction ltr`.

| Клавиши | Действие (при чтении справа налево) |
|---|---|
| `←`, `h` | следующая страница |
| `→`, `l` | предыдущая |
| `↓`, `j`, пробел | следующая (не зависит от направления) |
| `↑`, `k`, Backspace | предыдущая |
| `g` / `G` | первая / последняя |
| `q`, `Esc` | выход |

Текущее направление и номер страницы видны внизу экрана.

## Библиотека

```bash
yomi library scan ~/Манга    # собрать библиотеку
yomi library list            # что есть и сколько прочитано
yomi library resume          # где остановились
yomi library chapters 1      # главы тайтла (номер — из library list)
yomi library clean           # проверить, не пропали ли файлы
yomi info файл.cbz           # том или глава, есть ли разбиение внутри
```

Ожидаемая раскладка:

```text
~/Манга/
├── Название тайтла/
│   ├── Том 1.cbz
│   └── Том 2.cbz
└── Другой тайтл/
    └── Глава 1/     <- каталог с картинками тоже подходит
```

Если внутри CBZ есть `ComicInfo.xml` — его кладут Komga, Kavita и
Mihon — оттуда берутся название серии, авторы, жанры и номер тома.
Иначе номера угадываются по имени файла: `Том 3`, `v03`, `глава 12`.

### Тома и главы

`yomi` различает отдельную главу и целый том — по указанию в имени файла
(`Том 3`, `Глава 12`), по метаданным и, в последнюю очередь, по числу
страниц. Разбиение тома на главы определяется, только если оно размечено
в самом файле: закладками `Bookmark` в `ComicInfo.xml`, вложенными
каталогами внутри архива или номерами глав в именах страниц.

Если разметки нет, помогает `yomi info --deep`: в части изданий глава
открывается разворотом на два листа, и такая страница заметно шире
остальных. Это уже догадка по содержимому, поэтому результат помечается
как эвристика — границы стоит проверить глазами. Когда разворотов нет
или они разбросаны по всему тому, программа честно скажет, что определить
не смогла.

Чего `yomi` не делает — не режет том механически, «каждые двадцать
страниц». Главы бывают и по двенадцать страниц, и по пятьдесят, плюс
обложки и послесловия; такое деление ошибалось бы почти всегда, но
выглядело бы уверенно.

Прогресс сохраняется автоматически: следующий `yomi read` того же файла
продолжит с нужной страницы. Пересканирование прогресс не стирает.

## Качество картинки

Зависит от терминала. Полноценная графика — в kitty, ghostty и WezTerm;
в остальных страница приближается цветными юникод-блоками. Alacritty и
GNOME Terminal графических протоколов не поддерживают принципиально —
это их ограничение, а не ошибка yomi.

Что выбралось автоматически, видно так:

```bash
yomi -vv read файл.cbz 2>&1 | grep protocol
```

Пропорции страницы сохраняются всегда, и по умолчанию она не
растягивается сверх своего разрешения. Настраивается через `--fit` и
`--upscale`, см. [docs/CONFIG.md](docs/CONFIG.md).

## Сборка CBZ

Если сканы лежат папкой с картинками, их можно собрать в один файл,
который читается и в yomi, и в Komga, Kavita, Mihon:

```bash
yomi pack ~/сканы/Глава\ 1
yomi pack ~/сканы/том3 --series "Название" --volume 3 -o ~/Манга/том3.cbz
```

Порядок страниц — естественный: `page2.jpg` встанет перед `page10.jpg`.
В архив кладётся `ComicInfo.xml` с указанными метаданными.

## Правовая оговорка

`yomi` — клиент, который не размещает и не распространяет контент.
Пользователь сам отвечает за законность доступа к подключаемым
источникам. Поэтому в основной репозиторий не включаются источники
сомнительного правового статуса — механизм расширений позволяет
подключать их отдельно.
