# yomi (読み)

Терминальная читалка манги для Linux. Чтение локальных файлов, поиск и
загрузка из источников — без браузера, одним статическим бинарником.

**Статус:** в активной разработке. Актуальный код — в ветке [`dev`](../../tree/dev).

## Ветки

- `master` — только стабильные релизы.
- `dev` — текущая разработка, сюда идут фичи и правки.
