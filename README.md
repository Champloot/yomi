# yomi (読み)

Терминальная читалка манги для Linux. Локальные файлы, библиотека с
прогрессом, графика прямо в терминале — без браузера, одним статическим
бинарником.

> **В разработке.** Загрузки из сети нет — сознательно, см. раздел
> «Чего yomi не делает».

## Установка

Готовый бинарник со [страницы релизов](https://github.com/Champloot/yomi/releases)
— статический, работает на любом дистрибутиве, ничего доустанавливать
не нужно:

```bash
tar -xzf yomi-*-x86_64-unknown-linux-musl.tar.gz
cd yomi-*-x86_64-unknown-linux-musl
./yomi --version
sudo install -m755 yomi /usr/local/bin/
```

Из исходников:

```bash
git clone https://github.com/Champloot/yomi.git
cd yomi
cargo build --release
```

Нужен Rust 1.75 или новее. На NixOS достаточно `nix develop` —
подробности в [docs/nixos.md](docs/nixos.md).

Автодополнение и man-страница генерируются самим бинарником:

```bash
mkdir -p ~/.local/share/bash-completion/completions ~/.local/share/man/man1
yomi generate completions bash > ~/.local/share/bash-completion/completions/yomi
yomi generate manpage > ~/.local/share/man/man1/yomi.1
```

Каталоги может потребоваться создать: перенаправление вывода само их
не создаёт.

## Что умеет

```bash
yomi read том.cbz              # читать
yomi info том.cbz              # что внутри: том или глава, есть ли главы
yomi build ~/скачанные-главы/  # собрать том из отдельных глав
yomi pack ~/папка-с-картинками # собрать CBZ из картинок
yomi marks list том.cbz        # разметка глав
yomi library scan ~/Манга      # библиотека и прогресс чтения
```

## Чтение

```bash
yomi read ~/Манга/Тайтл/Том\ 1.cbz
yomi read ~/Манга/Тайтл/Том\ 1/     # каталог с картинками тоже подходит
```

По умолчанию читается справа налево, как в манге: **стрелка влево
листает вперёд**. Для комиксов — `--direction ltr`.

| Клавиши | Действие |
|---|---|
| `←` `h` | следующая страница |
| `→` `l` | предыдущая |
| `↓` `j` пробел | следующая (не зависит от направления) |
| `[` `]` | к началу предыдущей / следующей главы |
| `m` | отметить начало главы |
| `g` `G` | в начало / конец |
| `q` `Esc` | выход |

Качество картинки зависит от терминала: полноценная графика в kitty,
ghostty и WezTerm, в остальных — приближение цветными блоками. Alacritty
и GNOME Terminal графики не поддерживают принципиально.

## Сборка тома из глав

Если главы скачаны по отдельности, `build` соберёт из них том и сам
расставит границы глав — по числу страниц в каждом файле, **без
пролистывания**. Спойлеров при разметке не будет.

```bash
yomi build ~/главы/                      # разберёт и спросит неясное
yomi build ~/всё-вперемешку/             # разложит по томам и тайтлам
yomi build том33.cbz --add глава364.cbz  # дописать главу на её место
```

Номера тома и глав читаются из имён файлов, названия глав — тоже.
Границы записываются в `ComicInfo.xml` закладками, поэтому собранный том
откроется по главам и в Komga, и в Kavita, и в Mihon.

Подробности и разбор случаев — [docs/workflows.md](docs/workflows.md).

## Библиотека

```bash
yomi library scan ~/Манга
yomi library list
yomi library resume     # где остановились
```

Прогресс сохраняется сам и переживает пересканирование.

## Чего yomi не делает

**Не качает мангу из сети.** Единственный крупный источник с открытым
API не отдаёт лицензированные тайтлы — то есть всё популярное. Функция,
которая не работает ровно там, где нужна, раздражает сильнее, чем её
отсутствие. Наработки сохранены в ветке `net`.

**Не угадывает границы глав по числу страниц.** Главы бывают и по
двенадцать страниц, и по пятьдесят. Границы берутся из разметки в файле,
из числа страниц отдельных глав или ставятся вручную — но не выдумываются.

## Правовая оговорка

`yomi` — клиент, который не размещает и не распространяет контент.
Пользователь сам отвечает за законность доступа к тем файлам, которые
открывает.
