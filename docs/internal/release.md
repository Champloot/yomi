# Как выпустить релиз

## Перед тегом

```bash
make check                    # формат, clippy, тесты
cargo build --release --locked
cargo deny check              # лицензии и уязвимости зависимостей
```

Проверить вручную то, что тесты не покрывают:

- чтение в настоящем терминале, включая kitty-графику;
- `yomi build` на реальном наборе глав;
- `yomi library scan` на настоящей коллекции.

## Подготовка

1. В `CHANGELOG.md` заменить `## [Не выпущено]` на `## [X.Y.Z] — ГГГГ-ММ-ДД`
   и добавить новый пустой раздел «Не выпущено» сверху.
2. Поднять `version` в корневом `Cargo.toml` (поле `workspace.package`).
3. `cargo build` — чтобы обновился `Cargo.lock`.
4. Закоммитить: `chore(release): версия X.Y.Z`.

## Тег и публикация

```bash
git tag -a vX.Y.Z -m "yomi X.Y.Z"
git push origin master --tags
```

Дальше работает `.github/workflows/release.yml`: собирает статические
бинарники под `x86_64` и `aarch64`, прикладывает автодополнение и
man-страницу, создаёт **черновик** релиза. Проверьте содержимое и
опубликуйте вручную.

## Почему musl

Бинарник, собранный против системной glibc, не запустится на чужом
дистрибутиве — особенно собранный на NixOS, где он ссылается на
загрузчик из `/nix/store`. Статическая сборка под musl снимает вопрос
совместимости целиком: один файл работает везде.

Проверить самому:

```bash
rustup target add x86_64-unknown-linux-musl
cargo build --release --target x86_64-unknown-linux-musl
ldd target/x86_64-unknown-linux-musl/release/yomi   # not a dynamic executable
```

На NixOS для этого удобнее `nix develop` с добавленным `pkgsStatic`,
либо просто довериться CI.

## Нумерация версий

Пока версия младше 1.0, ломающие изменения допустимы в минорной версии,
но их нужно описывать в CHANGELOG отдельным разделом «Изменено».

Схема базы данных версионируется независимо (`PRAGMA user_version`).
Миграция вниз не поддерживается: если пользователь откатится на старую
версию yomi, база окажется новее, и программа честно об этом скажет,
а не испортит данные.

## Что проверить в готовом релизе

```bash
tar -xzf yomi-X.Y.Z-x86_64-unknown-linux-musl.tar.gz
cd yomi-X.Y.Z-x86_64-unknown-linux-musl
./yomi --version
sha256sum -c ../yomi-X.Y.Z-x86_64-unknown-linux-musl.tar.gz.sha256
```

Хорошо бы на машине с другим дистрибутивом — ради этого всё и затевалось.
