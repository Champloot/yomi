# Внутренние материалы

Здесь лежит то, что помогает **вести разработку**, но не является
документацией проекта: рабочие заметки, личные шпаргалки, план развития.

Эти файлы не попадают в архивы исходников, которые GitHub прикладывает
к релизам — за это отвечает `export-ignore` в `.gitattributes` в корне
репозитория. Пользователю, скачивающему релиз, они ни к чему.

| Файл | Что это |
|---|---|
| [rust-primer.md](rust-primer.md) | шпаргалка по Rust на материале этого проекта: для автора, переходящего с Go и Python. Не заменяет [официальную книгу](https://doc.rust-lang.ru/book/) и не претендует на роль учебника |
| [workflow.md](workflow.md) | повседневные команды и порядок работы |
| [roadmap.md](roadmap.md) | план этапов M0–M6 с отметками о готовности |

Если вы пришли сюда за документацией проекта, вам в другую сторону:

- как пользоваться — [README](../../README.md) в корне;
- настройки — [docs/CONFIG.md](../CONFIG.md);
- как устроено внутри — [docs/ARCHITECTURE.md](../ARCHITECTURE.md);
- как вносить правки — [CONTRIBUTING.md](../../CONTRIBUTING.md).
