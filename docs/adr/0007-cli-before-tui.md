# ADR-0007. CLI раньше TUI

## Контекст

Итоговый продукт задуман как полноэкранный интерфейс в духе Mihon.
Соблазн — начать сразу с него, потому что именно его увидит пользователь.

## Решение

Сначала команды (`yomi read`, `search`, `download`), затем TUI поверх
тех же функций ядра — этап M4.

## Альтернативы

**Сразу TUI.** Быстрее приводит к «вау», но логика неизбежно врастает
в обработчики клавиш, а тестировать полноэкранный интерфейс на порядок
труднее, чем вывод команды.

## Последствия

Каждая возможность доступна из скриптов и проверяется интеграционным
тестом по коду возврата и выводу. К моменту начала TUI ядро уже
обкатано, и остаётся только отрисовка.

Ограничение, которое надо держать: TUI не имеет права содержать логику.
Понадобилась функция, которой нет в ядре, — она пишется в ядре.
