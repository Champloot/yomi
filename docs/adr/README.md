# Журнал архитектурных решений

ADR (Architecture Decision Record) — короткая запись о значимом решении:
что решили, почему, какие были альтернативы и чем за это платим.

Смысл не в бюрократии. Через полгода вы не вспомните, почему выбрали
именно так, и потратите день на повторное обдумывание — либо, что хуже,
молча всё переделаете и наступите на те же грабли.

Формат: контекст → решение → альтернативы → последствия.
Записи не редактируются задним числом. Передумали — новая запись
со статусом «заменяет ADR-NNNN».
