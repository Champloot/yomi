# Коды возврата

`yomi` рассчитан на использование в скриптах, поэтому коды осмысленные,
а не «1 на всё».

| Код | Значение |
|---|---|
| 0 | успех |
| 1 | общая ошибка выполнения |
| 2 | неверные аргументы или битый конфиг |
| 4 | запрошенное не найдено |
| 5 | сеть недоступна или источник не отвечает |
| 6 | возможность ещё не реализована |
| 70 | внутренняя ошибка — так быть не должно |

Код 6 — сознательное решение: нереализованные команды не молчат, а
сообщают об этом, чтобы скрипт мог отличить «не умею» от «сделал».

Пример использования:

```bash
if yomi library resume > /dev/null 2>&1; then
    echo "есть незавершённая глава"
fi

yomi read "$file"
case $? in
    0) echo "прочитано" ;;
    4) echo "файл не найден" ;;
    6) echo "формат пока не поддерживается" ;;
esac
```
