# Сценарии

Разбор типичных задач по порядку: от «есть папка файлов» до «читаю с
разметкой глав».

## Собрать том из скачанных глав

Исходное: несколько CBZ, каждый — отдельная глава.

```bash
yomi build ~/скачанное/главы/
```

Программа разберёт имена, покажет состав и спросит только то, что не
удалось определить:

```
Найдено файлов: 3

  гл. 359      22 стр.  Долгое послевкусие
  гл. 360      20 стр.  Прокачка любви
  гл. 361      24 стр.  Павшая крепость

Тайтл: Название
Том:   33

Название тайтла [Название]: _
Номер тома [33]: _
Собрать том? [Y/n]: _
```

Без вопросов — `--yes`. Готовый файл: `Название_Vol_33.cbz`.

### Что читается из имён файлов

Позиция чисел роли не играет — важно, как они ведут себя в наборе:

| Имена | Разбор |
|---|---|
| `33_-_359_Название` | том 33, глава 359 |
| `_-_12_-_20_`, `_-_13_-_20_` | том 20 (не меняется), главы 12 и 13 |
| `Usogui_VOL-32` | том 32 — по подписи `VOL` |
| `ch012`, `ch013` | главы 12 и 13, том неизвестен |

Подпись (`том`, `vol`, `гл`, `ch`) важнее всего: её поставил человек.
Дальше — вариативность: что меняется от файла к файлу, то глава.
В последнюю очередь — величина: больший номер обычно глава.

Если номера не читаются вовсе:

```bash
yomi build ~/главы/ --start-chapter 359   # считать идущими подряд
```

## Разложить кучу файлов по томам

Если в каталоге лежат разные тома или вовсе разные произведения:

```bash
yomi build ~/скачанное/всё/
```

```
В каталоге несколько томов — найдено групп: 2

  Название — том 21, файлов 3
      _21_12_Название, _21_13_Название, _21_14_Название
  Название — том 22, файлов 1
      _22_12_Название
```

Деление идёт сначала по тексту имени (разные произведения не смешаются),
затем по номеру тома. Какая позиция чисел означает том, выбирается по
связности: три идущие подряд главы убедительнее одиночного совпадения
номеров. При неоднозначности программа предупредит.

Если разбиение вышло неверным — отмените, разложите файлы по папкам
руками и соберите каждую отдельно.

## Дописать пропущенную главу

```bash
yomi build том34.cbz --add ~/34_-_365_Игра_в_противоречия.cbz
```

Глава встанет **на своё место по номеру**, а не в конец: 365 между 364
и 366. Границы всех глав пересчитываются, прежние закладки сохраняются.

Если глава помечена другим томом, программа переспросит — это бывает
намеренно, но чаще оплошность.

## Разметить главы вручную

Когда отдельных глав нет, а том цельный. Порядок по убыванию точности:

**1. Разметка уже в файле** — ничего делать не нужно:

```bash
yomi info том.cbz     # покажет, есть ли границы
```

**2. Автоматика по разворотам** — если главы открываются разворотом:

```bash
yomi marks detect том.cbz --deep
yomi marks list том.cbz          # проверить результат
```

Это догадка по содержимому. Развороты встречаются и в середине глав, так
что границы стоит проверить.

**3. Вручную при чтении** — точно, но придётся листать:

```bash
yomi read том.cbz     # клавиша `m` на первой странице главы
```

Файл должен быть в библиотеке: отметки хранятся в базе.

```bash
yomi library scan ~/Манга
```

**Точечная правка:**

```bash
yomi marks add том.cbz 24 --title "Название"   # нумерация с единицы
yomi marks remove том.cbz 24
yomi marks clear том.cbz
```

## Собрать CBZ из папки картинок

Когда на руках россыпь страниц, а не готовые архивы:

```bash
yomi pack ~/сканы/глава1
yomi pack ~/сканы/том3 --series "Название" --volume 3
```

Порядок страниц естественный: `page2.jpg` встанет перед `page10.jpg`.

## Библиотека и прогресс

```bash
yomi library scan ~/Манга
yomi library list              # тайтлы и сколько прочитано
yomi library chapters 1        # состав тайтла
yomi library resume            # где остановились
yomi library clean             # проверить, не пропали ли файлы
```

Ожидаемая раскладка:

```text
~/Манга/
├── Название тайтла/
│   ├── Том 1.cbz
│   └── Том 2.cbz
└── Другой тайтл/
    └── Глава 1/     <- каталог с картинками тоже подходит
```

`library clean` без `--yes` ничего не удаляет, только показывает список:
если коллекция на съёмном диске и он не примонтирован, «пропавшими»
окажутся все файлы разом.

## Диагностика

```bash
yomi -vv read файл.cbz 2>&1 | grep protocol   # что выбрала автоматика
yomi info файл.cbz                            # что внутри файла
yomi config path                              # где лежат конфиг и база
```
