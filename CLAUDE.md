# Контекст проекта для Claude Code

Этот файл подхватывается автоматически в начале сессии. Держите его коротким
и актуальным: он тратит контекст в каждом разговоре.

## Что за проект

`yomi` — терминальная читалка манги для Linux. Чтение локальных файлов,
поиск и загрузка из источников, библиотека с прогрессом чтения.
Аудитория — русскоязычные пользователи Linux. Язык — Rust.

Текущий этап: **M0 (каркас) завершён, следующий M1 (локальное чтение)**.
Подробности: `docs/ROADMAP.md`.

## Нерушимые правила

1. **`yomi-core` не знает про `yomi`.** В ядре нет `println!`, `clap`
   и ANSI-кодов. Зависимость строго в одну сторону.
2. **В `commands/` нет бизнес-логики** — только «взять из ядра и напечатать».
   Появилась логика — переносим в ядро.
3. **stdout — данные, stderr — логи и ошибки.** Нарушать нельзя: ломает
   перенаправление вывода в файл.
4. **Тесты не ходят в сеть.** Никогда. Фикстуры или заглушки.
5. **`unsafe` запрещён** без записи в `docs/adr/`.
6. **Комментарии и текст для пользователя — по-русски**, имена в коде —
   по-английски.

## Проверка перед коммитом

```bash
cargo fmt --all

cargo test --workspace
```

## Как со мной работать

- Сначала план, потом код. На крупных задачах — покажи план и дождись «да».
- Задачи вертикальными срезами: не «напиши модуль viewer», а «покажи одну
  картинку в kitty и выйди».
- После каждого законченного куска — тесты и коммит по Conventional Commits
  (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`).
- Автор проекта знает Go и Python, Rust учит по ходу. Незнакомые конструкции
  (лайфтаймы, `Arc`, `dyn`, `async_trait`) поясняй прямо в комментариях
  или в ответе — коротко.
- Не добавляй зависимости без объяснения, зачем и что будет альтернативой.

## Карта кода

```
crates/yomi-core/src/
  model.rs    доменные типы: Manga, Chapter, Page, SearchQuery
  config.rs   конфигурация TOML + значения по умолчанию
  paths.rs    XDG-каталоги, переопределение через переменные окружения
  error.rs    перечисление ошибок ядра (thiserror)
  source.rs   трейт Source, Capabilities, Registry  ← точка расширения
  sources/    реализации источников (пока только demo)

crates/yomi-cli/src/
  cli.rs         декларация команд (clap derive)
  commands/      по модулю на команду
  exit.rs        коды возврата
  logging.rs     tracing в stderr
  tests/cli.rs   интеграционные тесты: запускают бинарник
```
